# This a Fast food finder:
It will search the users general area to find a fast food place near by.

# Whats on the page:
*   **Food near me button**: *This is the start of the page press to begin search.*
*   **Max distance**: *This is an interactble that allows for a wider search on the map.*
*   **Map**: *The map that shows the information on where the fast food place is.*
*   **Place deatails**: *This will show the locattion name, distance and link*
*   **Search block**: *Will display the Fast food place and distance from user*
